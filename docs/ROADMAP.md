# OpenStep Studio roadmap

## v0.1 — Usable prototype
- Import screenshots (PNG, JPEG, WebP)
- Annotate images with numbered markers, arrows, boxes, and highlights
- Organize tutorial steps with titles and descriptions
- Export local guides and save project data
- Make the interface usable on Android and desktop

## Next
- Improve accessibility and mobile editing controls
- Test export consistency across devices
- Add reliable PDF export and richer templates
- Add automated browser tests and a deployment workflow

Features are not marked complete until tested. All screenshot processing should remain local by default.
