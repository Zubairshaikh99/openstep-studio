# Security Policy

OpenStep Studio is a client-side editor. Do not post screenshots or backups containing private or sensitive information in a public GitHub issue.

To report a vulnerability, use GitHub's private vulnerability reporting feature if the repository owner enables it. Otherwise contact the maintainer privately using a verified contact method listed on their GitHub profile. Do not disclose exploitable vulnerabilities publicly before they can be evaluated.

The prototype does not provide end-to-end encrypted storage or guaranteed permanent backups. Saved browser data is accessible to users and scripts running in the same origin; treat local browser storage as a convenience, and protect your exported backups.
