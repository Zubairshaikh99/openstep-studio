# Contributing to OpenStep Studio

Thanks for helping make free, practical software better!

1. Search existing issues before opening a new one.
2. For major changes, discuss the feature in an issue first.
3. Work on a focused branch and keep pull requests small.
4. Run `npm test` and `npm run check` before submitting.
5. Include reproduction steps for bugs and screenshots only if they contain no private information.
6. Describe which browsers/devices you tested.

Respect contributors and users; assume good faith and keep discussions constructive.
